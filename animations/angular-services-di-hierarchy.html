Angular 22 Service Provider Scopes & Resolution Matrix
providedIn: 'root' Tree-shakable application singleton; lives for entire session RootEnvironmentInjector
providedIn: 'platform' Shared across multiple Angular microfrontend apps in same page PlatformInjector
providers: [Service] Component instance scoped; visible to template AND projected content ElementInjector (Open)
viewProviders: [Service] Restricted strictly to component view; hidden from <ng-content> ElementInjector (Isolated)
// Modern inject() with Resolution Modifiers & DestroyRef Teardown
@Component({
  standalone: true,
  providers: [ CartService ],
  viewProviders: [ InternalWidgetState ] // Hidden from <ng-content>
})
export class ProductCardComponent {
  private cart = inject(CartService);
  private parent = inject(GridComponent, { optional: true, skipSelf: true });
  private destroyRef = inject(DestroyRef).onDestroy(() => cleanup());
}
Resolution: Element ➔ Environment ➔ Platform ➔ Null | Modifiers: self, skipSelf, host, optional
