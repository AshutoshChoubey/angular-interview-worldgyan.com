Angular 22 Forms Architecture

3 Paradigms Matrix
Paradigm 01

Template-Driven Forms

Asynchronous model inferred by template directives. Ideal for simple inputs & filters.

  • Module: FormsModule
  • Binding: [(ngModel)]
  • Truth: DOM Template
Paradigm 02

Typed Reactive Forms

Synchronous, strictly-typed model declared in TypeScript. Enterprise multi-step wizards & FormArray.

  • Module: ReactiveFormsModule
  • Model: FormGroup <T>
  • Dynamic: FormArray & FormRecord
Paradigm 03

Signal Forms (Modern)

Fine-grained O(1) synchronous reactivity. toSignal() bridge + linkedSignal() draft resets.

  • Core: toSignal(valueChanges)
  • Derived: computed() validation
  • Resets: linkedSignal() sync
Typed Reactive Form Model Strict TypeScript 
private fb = inject(NonNullableFormBuilder);

readonly checkoutForm = this.fb.group({
  cardholderName: ['', [Validators.required]],
  billingEmail: ['', [Validators.email]],
  items: this.fb.array<string>(['SKU-101'])
});

// 100% typed raw value (no nulls):
const payload = this.checkoutForm.getRawValue();
Signal Forms & Zoneless State O(1) Reactive 
// 1. Reactive Form -> Signal bridge:
readonly formState = toSignal(
  this.checkoutForm.valueChanges,
  { initialValue: this.checkoutForm.getRawValue() }
);

// 2. Derived computed validation:
readonly isValid = computed(() => 
  this.formState().cardholderName.length > 3
);

// 3. Automatic reset with linkedSignal:
readonly draft = linkedSignal(() => this.initialData());
