Step 01

Generate PKCE

Creates code_verifier (128 char random string) + computes code_challenge.

Step 02

Auth Request

Redirects to IdP with code_challenge & code_challenge_method=S256.

Step 03

Auth Code

User logs in; IdP redirects back to Angular app with short-lived code in query param.

Step 04

Token Exchange

Angular POSTs code + code_verifier. IdP matches SHA256; returns JWT tokens!

PKCE Invariant: code_challenge = BASE64URL(SHA256(code_verifier)) Prevents Authorization Code Interception Attacks
// auth.service.ts — Angular 22 OAuth2 / OpenID Connect PKCE Flow async function initiateLogin() { const verifier = generateRandomString(64); const challenge = await sha256Base64Url(verifier); sessionStorage.setItem('pkce_verifier', verifier); // Safe in sessionStorage const authUrl = `https://auth.worldgyan.com/authorize?response_type=code` + `&client_id=worldgyan_spa&code_challenge=${challenge}&code_challenge_method=S256`; window.location.href = authUrl; }
