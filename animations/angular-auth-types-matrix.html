Authentication Architecture: Decision Matrix

4 Core Models Zero XSS Signals Ready

1. JWT Bearer Token

Stateless Microservices
Stateless
Token Storage: In-Memory Signal / Closure
XSS Resilience: Immune if kept out of LocalStorage
CSRF Resilience: 100% Immune (Custom Header)
Best For: Distributed APIs & Mobile
Angular 22 Integration req.clone({ setHeaders: { Authorization: `Bearer ${token}` } })

2. OAuth 2.0 + OIDC (PKCE)

Delegated Identity Providers
Max Security
Identity Providers: Auth0, Okta, Keycloak, Google
Secret Exposure: Zero Secret in SPA Code
Token Types: ID Token + Access + Refresh
Best For: Enterprise SSO & B2B Portals
Angular 22 Integration provideOAuthClient() + canActivate: [oauthGuard]

3. HttpOnly Cookie Sessions

BFF / Monolithic Same-Origin
XSS Immune
Token Storage: Browser Cookie Jar (HttpOnly)
XSS Resilience: JavaScript CANNOT read cookie!
CSRF Defense: SameSite=Strict + X-XSRF-TOKEN
Best For: BFF Architectures & Banking
Angular 22 Integration provideHttpClient(withXsrfConfiguration({ ... }))

4. Silent Refresh Mutex

Seamless Session Rotation
Zero Logout
Access Token TTL: 5–15 Minutes (Short-lived)
Refresh Token TTL: 7–30 Days (Rotated on use)
401 Resolution: switchMap Queue + Auto-Replay
Best For: SaaS Apps with Long User Sessions
Angular 22 Integration refreshTokenInterceptor with catchError + retry queue
Architecture Recommendation: BFF with HttpOnly Cookies OR In-Memory JWT + PKCE
